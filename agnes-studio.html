🖼️ 文生图范例 · image-2.1-flash
公式：[主体] + [场景 / 环境] + [风格] + [光照] + [构图] + [质量要求]
范例：日出时分薄雾峡谷上方的发光浮空城市，电影级写实风格，广角构图，丰富的建筑细节，柔和的金色光线，高视觉密度
🔄 图生图范例 · image-2.1-flash
公式：[改变要求] + [新风格 / 场景] + [需要添加或移除的元素] + [需要保留的元素]
范例：将白天街道场景改为电影级赛博朋克夜景，添加霓虹招牌和湿滑路面倒影，同时保留原始街道布局、相机角度和主要建筑形状
🏙️ 高信息密度图像范例 · image-2.1-flash
公式：[主体] + [次要细节] + [背景/环境] + [风格] + [光照] + [构图约束]
范例：建在悬崖上的大型奇幻港口城市，数百艘小船，层叠的石桥，发光的窗户，远山，多云的日落天空，电影级奇幻写实风格，广角构图，丰富的建筑细节，高视觉密度
🎬 文生视频范例 · video-v2.0
公式：[主体] + [动作] + [场景] + [镜头运动] + [光线] + [风格]
范例：一个年轻的宇航员走过红色沙漠星球，风中扬起尘土，电影级慢速跟拍镜头，戏剧性日落光照，逼真科幻风格
🖼️→🎬 图生视频范例 · video-v2.0
公式：[动起来的内容] + [保持稳定的主体]
范例：为角色添加轻微呼吸动作，头发随微风轻摆，背景灯光柔和闪烁，同时保持面部和服装一致
🎞️ 多图视频范例 · video-v2.0
公式：[起始场景 → 目标场景] + [过渡方式] + [一致性约束]
范例：用第一张图作为起始场景，第二张图作为目标场景。创建具有一致光照、自然动作和电影节奏的平滑转换
🎞️ 关键帧动画范例 · video-v2.0
公式：[关键帧 1 → 关键帧 2] + [保持角色/场景一致] + [自然过渡节奏]
范例：在第一个关键帧和第二个关键帧之间创建平滑过渡，保持角色身份、相机角度一致、场景间动作自然
